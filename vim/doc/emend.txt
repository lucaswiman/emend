1. INTRODUCTION                                           *emend-introduction*

emend.vim provides a fast, interactive search interface for Python codebases
using the emend refactoring tool.  It communicates with the `emend
editor-server` via JSON-RPC over stdio pipes, keeping the process warm for
sub-100ms searches.

Features:

- Auto-detecting search: symbols, patterns (`$`), selectors (`::`)
- Split-pane UI: navigable result list + file preview
- Async communication: non-blocking searches via job channels
- Cache warming: automatic index build with progress display
- Works in both Vim 8+ and Neovim

2. INSTALLATION                                           *emend-installation*

Prerequisites:~

Install emend (Python 3.10+): >
    uv tool install emend
<
Or for development, point to a local checkout (see |g:emend_command|).

vim-plug:~
>
    " From PyPI (requires emend on PATH or installed via uv):
    Plug 'lucaswiman/emend', { 'rtp': 'vim' }

    " Or from a local checkout:
    Plug '~/src/emend', { 'rtp': 'vim' }
<

packer.nvim:~
>
    use { 'lucaswiman/emend', rtp = 'vim' }
<

lazy.nvim:~
>
    { 'lucaswiman/emend', config = function() end,
      init = function()
        vim.opt.rtp:append(vim.fn.stdpath('data') .. '/lazy/emend/vim')
      end }
<

After installing, run `:helptags ALL` to index this help file.

3. COMMANDS                                                 *emend-commands*

                                                                     *:Emend*
:Emend [query]          Open the search prompt.  If [query] is given, search
                        immediately without prompting.

                                                               *:EmendSearch*
:EmendSearch {query}    Search for {query} without prompting.  The query is
                        auto-detected as one of:

                        - Symbol name:   `parse_pattern`
                        - Pattern:       `print($X)` (contains `$`)
                        - Selector:      `file.py::Class.method` (contains `::`)

                                                              *:EmendOutline*
:EmendOutline           Show all symbols in the current file (outline view).

                                                                 *:EmendRefs*
:EmendRefs [name]       Find references to [name].  Without an argument, uses
                        the word under the cursor.

                                                              *:EmendReplace*
:EmendReplace           Open a prompt for a find pattern and replacement.
                        After entering both, a diff preview is shown.
                        Press `<CR>` to apply the changes or `<Esc>` to cancel.

                                                                 *:EmendMove*
:EmendMove [dest_file]  Move the symbol under cursor to another file.  If
                        [dest_file] is not provided, prompts for a destination.
                        Shows a diff preview before applying.

                                                              *:EmendCallers*
:EmendCallers [name]    Find all call sites for [name].  Without an argument,
                        uses the word under the cursor.  Results are shown in
                        the search UI.

                                                              *:EmendCallees*
:EmendCallees [name]    Find all functions called by the symbol [name] (or
                        the symbol under the cursor).  Results are shown in
                        the search UI.

                                                            *:EmendTypeHover*
:EmendTypeHover         Show inferred type information for the symbol under
                        the cursor in the echo area.

                                                        *:EmendOutlineFilter*
:EmendOutlineFilter     Open an interactive outline of the current file with
                        real-time filtering.  As you type, the outline narrows
                        to matching symbols.

                                                                *:EmendStart*
:EmendStart             Start the emend editor-server process.  This happens
                        automatically when a Python file is opened (see
                        |g:emend_auto_start|), or on first search.

                                                                 *:EmendStop*
:EmendStop              Shut down the editor-server process.

                                                               *:EmendStatus*
:EmendStatus            Show index statistics (symbol count, file count, etc).

                                                              *:EmendReindex*
:EmendReindex           Re-index changed files and rebuild the FTS index.

4. HOT BUFFERS                                            *emend-hot-buffers*

Hot buffers allow the editor-server to see the current contents of open
buffers, including unsaved edits.  When hot buffers are active, local
operations such as file outline (|:EmendOutline|), go-to-definition, and
completion reflect the latest in-memory buffer state rather than the last
saved file on disk.

                                                    *:EmendHotBuffersEnable*
:EmendHotBuffersEnable  Register all currently open buffers with the server
                        and begin syncing edits as you type.  The server
                        receives the full buffer text on activation and on
                        each subsequent buffer update.

                                                   *:EmendHotBuffersDisable*
:EmendHotBuffersDisable Stop syncing buffer contents with the server.  The
                        server reverts to reading saved files from disk.

                                                        *g:emend_hot_buffers*
g:emend_hot_buffers     Boolean.  When 1, hot buffers are enabled
                        automatically as soon as the editor-server starts.
                        Default: 0 (hot buffers must be enabled manually
                        with |:EmendHotBuffersEnable|).
>
                        let g:emend_hot_buffers = 1
<

5. CONFIGURATION                                       *emend-configuration*

                                                           *g:emend_command*
g:emend_command         String.  Path to the emend executable.  When empty
                        (default), the plugin auto-detects:
                        1. uv tool path (`uv tool install emend`)
                        2. `emend` on $PATH
>
                        let g:emend_command = '~/src/emend/.venv/bin/emend'
<

                                                      *g:emend_project_root*
g:emend_project_root    String.  Override the project root directory.  When
                        empty (default), uses the current working directory.
>
                        let g:emend_project_root = '~/myproject'
<

                                                             *g:emend_limit*
g:emend_limit           Number.  Maximum search results.  Default: 50.

                                                        *g:emend_auto_start*
g:emend_auto_start      Boolean.  When 1 (default), automatically start the
                        emend editor-server the first time a Python file is
                        opened.  This keeps the server warm so that searches
                        are fast.  Set to 0 to disable and start manually
                        with |:EmendStart|.

                                                    *g:emend_preview_height*
g:emend_preview_height  Number.  Height of the search UI as a percentage of
                        the editor height.  Default: 60.

                                                  *g:emend_default_mappings*
g:emend_default_mappings
                        Boolean.  When 1, define default key mappings:
                        `<Leader>es`  →  |:Emend|
                        `<Leader>eo`  →  |:EmendOutline|
                        `<Leader>er`  →  |:EmendRefs|
                        `<Leader>eR`  →  |:EmendReplace|
                        `<Leader>em`  →  |:EmendMove|
                        `<Leader>ec`  →  |:EmendCallers|
                        `<Leader>eC`  →  |:EmendCallees|
                        `<Leader>et`  →  |:EmendTypeHover|
                        `<Leader>eO`  →  |:EmendOutlineFilter|
                        Default: 0 (no mappings created).

                        These mappings are also enabled when the project
                        configuration sets `default_mappings = true` (see
                        |emend-project-config|).  Existing mappings are left
                        alone so user keymaps are not overwritten.

6. KEY MAPPINGS                                             *emend-keymaps*

Inside the search results window:

    Navigation:~

    `j` / `<Down>`      Move selection down
    `k` / `<Up>`        Move selection up
    `<C-d>`             Move selection down 10 lines
    `<C-u>`             Move selection up 10 lines
    `gg`                Jump to first result
    `G`                 Jump to last result
    `<CR>`              Open the selected file at the matching line
    `q` / `<Esc>`       Close the search UI
    `/`                 Start a new search
    `<C-h>`             Open query history overlay

    Actions:~

    `r`                 Rename the selected symbol
    `R`                 Find references to the selected symbol
    `c`                 Find callers of the selected symbol
    `C`                 Find callees of the selected symbol
    `t`                 Show type information for the selected symbol
    `m`                 Move the selected symbol to another file

Inside the interactive search input:~

    `<C-h>`             Open query history overlay
    `<C-r>`             Cycle forward through query history
    `<C-f>`             Cycle backward through query history
    `<C-n>` / `<Down>`  Move selection down in results
    `<C-p>` / `<Up>`    Move selection up in results
    `<C-Space>`         Trigger completion

Inside the query history overlay:~

    `j` / `<Down>`      Move selection down
    `k` / `<Up>`        Move selection up
    `<CR>`              Recall the selected query into the picker and search
    `<Esc>` / `q`       Dismiss the overlay

                                                      *emend-provenance*
Provenance~

The search header shows a provenance tag indicating how results were
obtained:

    `[indexed]`   Symbol index (fast, requires built index)
    `[files]`     File path matching
    `[pattern]`   Tree-sitter pattern search
    `[grep]`      Regex/grep fallback
    `[selector]`  Direct selector resolution

This makes it obvious whether results came from the index, a pattern
search, or a fallback mode.

7. PROJECT CONFIGURATION                              *emend-project-config*

Plugin behavior can also be configured per-project via configuration files,
which override the Vim global defaults.

`.emend/config.toml`:~
>
    [vim]
    limit = 50              # max results per search
    preview_height = 60     # preview pane height (%)
    default_mappings = true  # enable <Leader>e* mappings
<

`pyproject.toml`:~
>
    [tool.emend.vim]
    limit = 50
    preview_height = 60
    default_mappings = true
<

The `limit` and `preview_height` keys correspond to |g:emend_limit| and
|g:emend_preview_height|.  The `default_mappings` key corresponds to
|g:emend_default_mappings|.

8. ARCHITECTURE                                         *emend-architecture*

The plugin spawns `emend editor-server` as a child process and communicates
via newline-delimited JSON-RPC over stdin/stdout pipes.

The server keeps a SQLite database (with FTS5 trigram indexing) warm in
memory, enabling sub-5ms symbol lookups and fast pattern searches.

On first use, if the index does not exist, the plugin automatically runs
`emend index -vv` and displays progress in the preview pane.  This one-time
index build typically takes 5-15 seconds for a medium-sized codebase.

JSON-RPC methods:~

    search          Auto-detect mode and search
    symbols         Symbol name search
    pattern         Code pattern search (supports `$` metavars)
    selector        Resolve `file.py::Sym.path` selectors
    references      Find references by qualified name
    file_symbols    File outline (all symbols in a file)
    query_history   Recent query history (session-scoped)
    status          Index statistics
    reindex         Refresh stale files + rebuild FTS
    shutdown        Clean server exit
